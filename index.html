Experience

  • Bilibili Senior Algorithm Engineer

    Shanghai, China · Jul 2019 – Present

    Core member of the team building Bilibili’s large-scale online ad recommendation system.

    • Generative retrieval. Designed and deployed a lightweight model that generates candidates in real time for e-commerce recommendations.
    • Pre-ranking. Trained the pre-ranker to select candidates as a set using the final ranker’s ordering. This shift from pointwise prediction substantially improved pre-ranking efficiency.
    • Delayed feedback in final ranking. Developed a training framework that incorporates late conversions as positive examples while keeping the conversion-rate model stable.
    • Scaling feature interactions. Co-designed MLCC, now the feature-interaction backbone of Bilibili’s ad ranking system. Scaling it across successive deployments substantially increased advertiser value within production latency limits.
